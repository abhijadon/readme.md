## Q1. What is a Computer?

### Answer (English)

A computer is an electronic machine that accepts input, processes it, and produces output according to given instructions.

It performs calculations, stores data, and executes programs to complete tasks quickly and accurately.

### Answer (English)

A program is a set of instructions written in a programming language that tells a computer what to do.

It is created to perform a specific task, such as calculating numbers, managing data, or displaying information.

## Q4. What is Programming?

### Answer (English)

Programming is the process of writing instructions (code) for a computer using a programming language.

It involves designing, writing, testing, and maintaining programs to solve problems or perform tasks.

## Q5. What is a Programming Language?

### Answer (English)

A programming language is a formal language used to give instructions to a computer.

It allows programmers to write code that tells the computer what to do. These instructions can perform tasks such as calculations, data processing, automation, or controlling hardware.

Programming languages follow specific rules and syntax so that the computer can understand and execute the commands correctly.

**Examples:** Python, Java, C++, JavaScript

---

## उत्तर (Hindi)

प्रोग्रामिंग लैंग्वेज एक औपचारिक भाषा है जिसका उपयोग कंप्यूटर को निर्देश देने के लिए किया जाता है।

इसकी मदद से प्रोग्रामर ऐसा कोड लिखते हैं जो कंप्यूटर को बताता है कि क्या करना है। ये निर्देश गणना करना, डेटा प्रोसेस करना, ऑटोमेशन करना या किसी डिवाइस को नियंत्रित करना जैसे कार्य कर सकते हैं।

हर प्रोग्रामिंग लैंग्वेज के अपने नियम (syntax) और संरचना होती है, जिससे कंप्यूटर उसे सही तरीके से समझकर execute कर सके।

**उदाहरण:** Python, Java, C++, JavaScript

## Q6. What are the Types of Programming Languages?

### Answer (English)

These languages have features of both low-level and high-level languages.

## Q7. What is the Difference Between Compiled and Interpreted Language?

### Answer (English)

### Compiled Language
A compiled language converts the entire program into machine code before execution.

Examples:
- C
- C++

Characteristics:
- Faster execution
- Compilation required before running
- Errors shown after full compilation

### Interpreted Language
An interpreted language executes the program line by line using an interpreter.

Examples:
- Python
- JavaScript

Characteristics:
- No manual compilation required
- Errors shown immediately
- Slower than compiled languages

---

### उत्तर (Hindi)

### कम्पाइल्ड लैंग्वेज

## Q13. Explain Python Execution Model

### Answer (English)

Python follows this execution process:

1. Source Code (.py file)
2. Compilation into Bytecode (.pyc file)
3. Execution by Python Virtual Machine (PVM)

If there is a syntax error, the interpreter shows an error before execution.

---

### उत्तर (Hindi)

Python का execution मॉडल इस प्रकार है:

1. Source Code (.py फाइल)
2. Bytecode में compilation
3. Python Virtual Machine (PVM) द्वारा execution

यदि syntax error होगा, तो interpreter पहले ही error दिखा देगा।

## Q14. What is a Variable in Python?

### Answer (English)

A variable is a name used to store data in memory.

In Python, we do not need to declare the type of a variable. The type is assigned automatically based on the value.

Example:

name = "Rahul"  
price = 99.5

### Answer (English)

Data types define the type of data a variable can hold.

is_active = True  # boolean

type(x)
