# Q1. What is a Programming Language?

## Answer (English)

A programming language is a formal language used to give instructions to a computer.

It allows programmers to write code that tells the computer what to do. These instructions can perform tasks such as calculations, data processing, automation, or controlling hardware.

Programming languages follow specific rules and syntax so that the computer can understand and execute the commands correctly.

**Examples:** Python, Java, C++, JavaScript

## उत्तर (Hindi)

प्रोग्रामिंग लैंग्वेज एक औपचारिक भाषा है जिसका उपयोग कंप्यूटर को निर्देश देने के लिए किया जाता है।

इसकी मदद से प्रोग्रामर ऐसा कोड लिखते हैं जो कंप्यूटर को बताता है कि क्या करना है। ये निर्देश गणना करना, डेटा प्रोसेस करना, ऑटोमेशन करना या किसी डिवाइस को नियंत्रित करना जैसे कार्य कर सकते हैं।

हर प्रोग्रामिंग लैंग्वेज के अपने नियम (syntax) और संरचना होती है, जिससे कंप्यूटर उसे सही तरीके से समझकर execute कर सके।

**उदाहरण:** Python, Java, C++, JavaScript
