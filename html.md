# 📘 Complete HTML & HTML5 Tags Reference

This repository contains a **complete and well-structured list of all HTML and HTML5 tags**.  
It is useful for **beginners, students, interviews, exams, and quick revision**.

---

## 📌 1. Document Structure Tags

These tags define the basic structure of an HTML document.

- `<html>` – Root element of HTML page  
- `<head>` – Metadata container  
- `<title>` – Page title  
- `<body>` – Main visible content  

---

## 📌 2. Metadata Tags

Used inside `<head>` for SEO, responsiveness, and linking resources.

- `<meta>`  
- `<link>`  
- `<style>`  
- `<base>`  

---

## 📌 3. Text & Heading Tags

Used to display text content.

- `<h1>` to `<h6>` – Headings  
- `<p>` – Paragraph  
- `<br>` – Line break  
- `<hr>` – Horizontal line  

---

## 📌 4. Text Formatting Tags

Used to style and format text.

- `<b>` – Bold  
- `<strong>` – Important text  
- `<i>` – Italic  
- `<em>` – Emphasized text  
- `<u>` – Underline  
- `<mark>` – Highlighted text  
- `<small>` – Smaller text  
- `<del>` – Deleted text  
- `<ins>` – Inserted text  
- `<sub>` – Subscript  
- `<sup>` – Superscript  
- `<s>` – Strikethrough text  

---

## 📌 5. Links & Image Tags

Used to add links and images.

- `<a>` – Anchor / Link  
- `<img>` – Image  
- `<map>` – Image map  
- `<area>` – Image map area  

---

## 📌 6. List Tags

Used to create lists.

- `<ul>` – Unordered list  
- `<ol>` – Ordered list  
- `<li>` – List item  
- `<dl>` – Description list  
- `<dt>` – Term  
- `<dd>` – Description  

---

## 📌 7. Table Tags

Used to create tables.

- `<table>` – Table  
- `<caption>` – Table caption  
- `<thead>` – Table header  
- `<tbody>` – Table body  
- `<tfoot>` – Table footer  
- `<tr>` – Table row  
- `<th>` – Header cell  
- `<td>` – Data cell  
- `<colgroup>` – Column group  
- `<col>` – Column  

---
